# ブランド資料(Duo Cruise・Duo Slate)

2 つのアプリのロゴ・アイコン・起動演出・起動音の素材と、その決まりをまとめたもの(2026-10-29 時点)。
アプリに組み込んだ素材は、ここから各アプリの置き場へ写して使っている。素材を差し替えるときは、ここを原本として両方を直す。

```
assets/brand/
├── duo-cruise/
│   ├── logo/     ロゴ(SVG)
│   ├── symbol/   シンボル(色付き・一色)
│   ├── icon/     アプリアイコン
│   ├── splash/   起動画面(縦・カラーの 1 枚絵)
│   └── sound/    起動音「ブルーム」と、その作り方
└── duo-slate/
    ├── logo/  symbol/  icon/  splash/
```

---

## 共通の意匠

- **ロゴ**: 字間を大きく取った細身の欧文。「DUO」を暖色(朱・オレンジ)、後半(CRUISE / SLATE)を寒色(空色・青)で塗り分け、下に小さく「LOVE rhetoric」を添える。
- **配色**: 暖色から寒色への流れ。アイコンの色は次の 6 色(Duo Slate の昼のネオン「DuoNEON」も同じ並び)。

  | 朱 | オレンジ | 桃 | 淡い水色 | 空色 | 青 |
  |---|---|---|---|---|---|
  | `#F0694A` | `#FC8C54` | `#FFB56E` | `#96D1FF` | `#59A1F5` | `#2959D1` |

- **昼と夜**: どちらにするかは OS のダーク表示に従う。昼は白地に「for-white」の素材、夜は黒地に「for-black」の素材を使う。
- **素材の名前の決まり**
  - `for-white` / `for-black`: 白地用 / 黒地用(色付き)
  - `mono-black` / `mono-white`: 黒一色(昼の起動演出の始め) / 白一色(夜の起動演出の始め)
  - `gradient`: ロゴの色付き版。`gradient-glow-for-black` は夜用で、文字の周りがわずかに光る
- **角丸を使わない(Duo Cruise の画面)**。アプリアイコンの角丸は OS が付ける。

## Duo Cruise

### シンボル
暖色と寒色、2 枚の角丸の板が斜めに重なる(左右 2 画面がひとつになる、の意)。板は何層も重なり、外側ほど淡い。

| ファイル | 用途 |
|---|---|
| `symbol/duocruise-symbol-for-white.webp` | 白地用(色付き)。1024×1024 |
| `symbol/duocruise-symbol-for-black.webp` | 黒地用(色付き) |
| `symbol/duocruise-symbol-mono-black.webp` | 黒一色(昼の起動演出の始め) |
| `symbol/duocruise-symbol-mono-white.webp` | 白一色(夜の起動演出の始め) |

### ロゴ
`logo/` の SVG 5 種。一色版(`for-white` / `for-black`)、色付き(`gradient-for-white` / `gradient-for-black`)、夜の起動用(`gradient-glow-for-black`)。

### アプリアイコン
**白地に、色付きのシンボル**(採用)。

| ファイル | 中身 |
|---|---|
| `icon/duocruise-android-launcher-foreground.png` | Android のアダプティブアイコンの前景(432×432)。背景は白。アプリでは `res/mipmap-anydpi-v26/ic_launcher.xml` |
| `icon/duocruise-icon-1024-light.webp` | 白地のアイコン 1024×1024(見本・配布用) |
| `icon/duocruise-icon-1024-dark.webp` | 黒地のアイコン 1024×1024(見本) |
| `icon/duocruise-icon-tile-for-white.webp` / `-for-black.webp` | 演出用のタイル 1200×1200 |

### 起動演出(OTTO 1480×480)
一色版の上に色付き版を重ねておき、時間差で入れ替える。「墨が抜けて色が出る」(昼)、「光が色に落ち着く」(夜)。

| 時刻 | 動き |
|---|---|
| 0.5 〜 2.0 秒 | 色付き版が現れる(透明度 0 → 1、ease-in-out) |
| 1.4 〜 2.9 秒 | 一色版が消える(透明度 1 → 0、ease-in-out) |
| 2.9 〜 3.6 秒 | 0.7 秒で滲みながら消える(ぼかし 0→28dp と透明)。同時にメイン画面が、滲んだところ(ぼかし 28dp)から澄んで現れる。初回は案内へ |

- **重ね方**: 一色版と色付き版は同じ位置・同じ大きさでぴったり重ね、一色版を上に置く。同時に切り替えると途中で全体が薄く濁るため、必ずこの時間差にする。
- **配置**: 上にシンボル、下にロゴ。横も縦も中央。シンボルは画面の高さの 36%、ロゴは高さの 92% の幅、間は 6.5%。
- **昼**: 白地。シンボル `mono-black → for-white`、ロゴ `logo-for-white → logo-gradient-for-white`。
- **夜**: 黒地。シンボル `mono-white → for-black`、ロゴ `logo-for-black → logo-gradient-glow-for-black`。
- **動きを減らす設定**: 「視差効果を減らす」「アニメーションを減らす」がオンなら動かさず、色付き版を 1.2 秒そのまま見せる。
- **CarPlay がつながるまで**: CarPlay の枠いっぱいに、同じシンボル(夜の素材)を置き、「墨が抜けて色が出る」を 3.6 秒で一往復、ゆっくり繰り返す(大きさ・位置は動かさない)。下に今の様子の文を小さく添える。映像が届いたら 0.4 秒で溶けて消える。起動画面が滲んで消えたとき、この演出がすでに始まっているので、起動演出が地続きで続いて見える
- **OS の起動画面**: Android 12 以降の標準の起動画面(SplashScreen)は自由に動かせないため、背景色(昼は白・夜は黒)だけにし、直後の自前の画面(`SplashView`)で演出を出す。背景色をそろえて、切り替わりで色が跳ねないようにする。
- `splash/duocruise-boot-portrait-color.png`: 演出が終わった姿(昼・カラー)を縦長(1320×2868)にした 1 枚絵。縦長では、横長の比率のままだとシンボルが小さいため、シンボルを幅の 56%、ロゴを幅の 80% にしている。

### 起動音「ブルーム」
色が出始める 0.5 秒から柔らかな和音がふくらみ、色が出きる 2.0 秒を頂点に、2.9 秒で余韻へ。さりげなく、演出に合わせた音。

| 項目 | 値 |
|---|---|
| 和音 | 昼: D の maj9(D4 を根音に、完全 5 度・長 7 度・9 度・長 3 度上を重ねる)+ 1 オクターブ下の D。夜: 4 度下の A の maj9(低く柔らかく) |
| 鳴り方 | 0.5 秒から 0.06 秒ずつずらして鳴らす。三角波、立ち上がり 1.2 秒、2.9 秒かけて消える。互い違いに ±6 セントずらして揺らぎを出す |
| 音色 | ローパス 5200 Hz → 900 Hz。残響 2.6 秒(ノイズから作る)、残響の割合 0.45 |
| ファイル | `sound/bloom-day.wav`、`sound/bloom-night.wav`(48 kHz・ステレオ・約 4.6 秒)。アプリでは `res/raw/boot_bloom_day.wav` / `boot_bloom_night.wav` |
| 作り方 | `sound/bloom-render.html` をブラウザで開き、`renderBloom(0)`(昼)/ `renderBloom(-5)`(夜)で WAV に書き出す |

- 鳴らすかどうかは、メニュー › システム › 起動音 で切り替えられる(初期値はオン)。
- 候補は 4 つ(A ブルーム・B グラス・C エア・D デュオ)作り、A を採用した。

## Duo Slate

### シンボル
**「ひとつの板」を斜め 45° に傾けたもの**。奥の暖色から手前の寒色へ、板が重なってめくれる。Duo Cruise と同じ意匠で、板の数と向きで描き分ける。
縦長の板・横長の板・斜め 25° / 35° / 45° を比べ、45° に決めた。

| ファイル | 用途 |
|---|---|
| `symbol/duoslate-symbol-for-white.png` / `-for-black.png` | 色付き |
| `symbol/duoslate-symbol-mono-black.png` / `-mono-white.png` | 一色(起動演出の始め) |

### ロゴ
`logo/` の SVG 5 種。名前の決まりは Duo Cruise と同じ。字形も Duo Cruise と同じ。

### アプリアイコン
白地(ライト)・黒地(ダーク)の 2 枚。iPhone はダークモードで黒地のアイコンに切り替わる。Mac 用の大きさ(16〜512 の @1x/@2x)はアプリの `Assets.xcassets/AppIcon.appiconset` にある。

| ファイル | 中身 |
|---|---|
| `icon/duoslate-icon-1024-light.png` | 白地 1024×1024 |
| `icon/duoslate-icon-1024-dark.png` | 黒地 1024×1024 |

### 起動演出(約 1 秒・音なし)
手元で何度も開くアプリなので、短く。演出が質をつくる。

| 時刻 | 動き |
|---|---|
| 0.10 〜 0.55 秒 | 色付き版が現れる(ease-in-out) |
| 0.35 〜 0.80 秒 | 一色版が消える(ease-in-out) |
| 0.85 〜 1.10 秒 | 0.25 秒で溶けて、タッチパッドの画面へ |

- **縦向き**: 上にシンボル、下にロゴ。シンボルは画面の幅の 62%、ロゴは幅の 70%、間は高さの 5%。
- **横向き**: 左にシンボル、右にロゴ。シンボルは高さの 42%、ロゴは高さの 62% の幅、間は高さの 8%。
- **昼夜・重ね方・動きを減らす設定**: Duo Cruise と同じ(動きを減らす設定がオンなら、色付き版を 0.6 秒見せる)。
- **OS の起動画面**: iPhone の起動画面は静止画のみのため、背景色(`LaunchBackground`、昼は白・夜は黒)だけにし、直後の自前の画面(`Splash.swift`)で演出を出す。
- `splash/duoslate-boot-portrait-color.png`: 縦向きの演出が終わった姿(昼・カラー、1320×2868)。アプリの縦向きと同じ比率。
- 「Duo Slate について」の画面も、この色付きのシンボルとロゴを同じ並びで出す。
