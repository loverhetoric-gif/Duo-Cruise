# Duo Slate 仕様書(2026-10-29 時点)

Duo Slate(旧名 Duo Pad、2026-10-28 に改名)は、iPhone と Mac を Duo Cruise のタッチパッドにするアプリです。iPhone・Mac で動く 1 つのアプリ(SwiftUI)で、置き場は `apps/slate`。
確かめていないことには「(未確認)」と書いています。ロゴ・アイコン・起動演出の素材と決まりは [assets/brand/README.md](../assets/brand/README.md)、受け手の Duo Cruise は [Duo-Cruise仕様書.md](Duo-Cruise仕様書.md) にあります。

---

## 1. 目的

- 車の画面に触れずに、手元の iPhone で Duo Cruise(CarPlay・YouTube・メニュー)を操作する
- Duo Cruise の外(OTTO のホーム画面・ほかのアプリ)でもカーソルで操作する(汎用モード)
- iPhone は主に縦向きで使う。横向きにも対応する

---

## 2. つながり

- 車の中の Wi-Fi(CarPlay と同じ)で、OTTO の Duo Cruise に直接つながる。外のサーバーは通らない
- Bonjour(`_duopad._tcp`)で自動で見つける。見つからないときだけ、設定の「接続先の指定」に入れた IP アドレスへつなぐ
- 指の動きは 1 つずつすぐ送る(Nagle を切る)。送った時刻を付け、OTTO 側が送った間隔どおりに再生して Wi-Fi の揺れを吸収する
- 1 秒ごとに生きているかを確かめ、往復の時間を測る。切れたら 0.5 秒後に自動でつなぎ直す。30 秒ごとに往復の時間とつなぎ直した回数を OTTO へ送る(記録シートに残る)
- 前面に戻ったら、切れていればすぐつなぎ直す。使っている間は画面を消さない
- 通信の決まり(指示の一覧)は `apps/duo/.../PadInput.java` と `PadServer.java` の説明にある

**変えないもの(互換のため旧名のまま)**: バンドル ID `com.yuki.duocruise.pad`(変えると別のアプリ扱いになり、設定が消える)、Bonjour の名前 `_duopad._tcp`(OTTO 側とそろえる必要がある)。

## 3. iPhone の操作

| 操作 | 動き |
|---|---|
| 1 本指でなぞる | カーソルを動かす。速さに応じて加速(ゆっくりは細かく、速くは遠くまで)。1px 未満の動きも捨てない |
| 軽く触れて離す | 押す(タップ) |
| 0.4 秒じっと押す | ドラッグ(押したまま動かす)。離すと終わる |
| 2 本指 | 2 本の指としてそのまま OTTO へ(スクロール・ピンチ)。Duo Cruise のメニューのスライダーもなぞって動かせる |

**下のボタン**(枠のないアイコンだけ。ダークでは淡く光る):戻る・ホーム・タスク(長押しで Duo Cruise のメニュー)・キーボード。
キーボードで確定した文字を OTTO へ送る(日本語の変換中は送らない。空のときの削除は 1 文字消す、改行は決定)。CarPlay 用の Wi-Fi のパスワードもここから入れる。

**画面の上**: 左上に小さく「SETTING」(押すと設定)。右上に接続の状態(縁の光と同じ色・同じ動きの文字)。どちらも画面の角の丸みの内側に収める。

## 4. 縁の光

画面の縁(画面と同じ曲線)に沿って光る。**光は自分では動かず、操作と出来事に答える**。

| 場面 | 光 |
|---|---|
| つながっている間 | 選んだネオンの配色がゆっくり縁を巡る。操作している側(左・右)の半分を強く、反対側を弱く(1 画面は左右同じ) |
| 指が触れている間 | 指に近い縁が灯る(0.15 秒で灯り、離すと 0.6 秒で引く) |
| Duo Cruise につながった | 青 |
| CarPlay の Bluetooth がつながった | 緑 |
| 切れた | 赤。切れている間は、うっすら赤が息をするように残る |
| 操作する側を切り替えた | 操作している側を強く光らせる |
| 曲がり角が近づいた(Duo Cruise Unlimited Edition) | 曲がる側(左・右)の縁だけを、Duo Cruise で選んだ色・強さで光らせる。OTTO から「`t L FFC24F 55`」(側・色・強さ%)が届いたとき |

- 出来事の光は、面全体が一瞬その色に染まり、縁へ引いて流れ、2.4 秒でゆっくり消える(0.35 秒で灯り 1.3 秒まで保つ)
- **ライト(明るい配色)**: 白い地では光を足しても見えないため、色を「重ねる」(multiply)で見せる。普段の光はアイコンの配色(DuoNEON)。接続完了の青と切断の赤は、普段の光と紛れない 1 色(澄んだ鮮やかな青・青みのある深い赤)
- **ダーク**: 光を「足す」(screen)
- 作りは 3 層(広い裾 46pt・ぼかし 28 / 中 10pt・ぼかし 7 / 外側の細い線 1.6pt)
- **描画の負荷**: 回るグラデーションは GPU で描かせる(`drawingGroup`)。そのままだと iOS が 1 コマごとに CPU で画面全体を塗り直し、アプリ全体が 1 秒 12 コマに落ちていた(実機で計測。直した後はメインスレッド 101% → 14%、60 コマ/秒、引っかかり 0)。GPU で描くと太いにじみが縁で 2 割ほど弱く出るため、1.35 倍にして直す前と画素で合わせてある。**光の質は落とさない**

## 5. 設定

左上の「SETTING」(または右上の接続の状態)を押すと開く。文言は一般的なアプリの標準の言葉を使う(内部の呼び名・造語・機種名を出さない)。

| 項目 | 内容 |
|---|---|
| 動きの速さ | 感度(0.3〜3.0、初期 1.0)、加速(0〜3.0、0 = 加速なし、初期 1.0) |
| ダークモード | オン / オフ / デバイスの設定(初期) |
| タッチパッドの配色 | ライト: ホワイト・ペーパー・ミスト / ダーク: ブラック・スミ・スレート |
| ネオンの配色 | ライト・ダークそれぞれ DuoNEON・ホワイト・オーシャン・アンバー(初期はライト DuoNEON、ダーク ホワイト) |
| 接続先の指定(通常は不要) | 空欄なら自動で見つける。うまくつながらないときだけ IP アドレスを入れる |
| 接続 | 再接続 |
| Duo Slate について | 起動演出と同じ色付きのシンボルとロゴ、バージョン |

- Duo Cruise の外(ホーム等)を操作している間は、Duo Cruise の中とひと目で見分けられるグレーの面にする

---

## 6. 起動とアイコン

- **起動演出**: 約 1 秒・音なし。一色 → 色付きのシンボルとロゴ。縦は上にシンボル・下にロゴ、横は左にシンボル・右にロゴ。詳細は [assets/brand/README.md](../assets/brand/README.md)
- **アプリアイコン**: 斜め 45° の「ひとつの板」。白地(ライト)と黒地(ダーク)。Mac 用の大きさもそろえてある

---

## 7. 多言語

英語(既定)・日本語・中国語(簡体・繁体)・韓国語・ドイツ語・フランス語・スペイン語・イタリア語の 9 言語(Duo Cruise と同じ)。9 つにない言語の端末では英語で出す。

- 文言の原本は `apps/slate/i18n/strings.py`。`python3 -I apps/slate/i18n/gen.py` で `Localizable.xcstrings` と `InfoPlist.xcstrings`(ローカルネットワークの許可の説明)を書き出す
- 言葉が長くなる言語(独・仏・西・伊)は、設定の見出しからアプリ名を省いて 1 行に収める
- 英・独・仏・中(簡体)・韓をシミュレーターで確認。日本語・繁体・西・伊は(未確認)
- 「SETTING」と「Duo Cruise」「Bluetooth」「DuoNEON」は名前として訳さない

---

## 8. Mac

- 窓をクリックすると、Mac のカーソルを Duo Slate が捕まえる(画面の端で止まらず、動きはすべて OTTO のカーソルへ)。Esc、またはほかのアプリに移ると放す
- クリック = 押す、押したまま動かす = ドラッグ、2 本指 = スクロール、右クリック = 戻る。キーボードの文字はそのまま OTTO へ(Return = 決定、Delete = 1 文字消す)
- 省電力でアプリを眠らせない(App Nap で合図が止まり、往復 11 秒・つなぎ直し 25 回になっていたため)
- 設定は感度・ダークモード・再接続。「Duo Slate について」はアプリのメニューから
- 開発用に MAZDA コマンダー風の操作盤を出せる(Duo Cruise 本体には付けない)

---

## 9. 作り方

```
brew install xcodegen
cd apps/slate && xcodegen generate
open DuoSlate.xcodeproj
```

確認用の切り替え(デバッグ版のみ): 環境変数 `DUO_OFFLINE=1` でつながっていないときの見た目、`DUO_DAY=1` でつながっていても昼の配色。
